1. Por qué ves "Doble Cámara" y por qué no escanea
El Problema Visual (Doble Cámara): El problema está en ScanScreen.tsx. Estás usando React (probablemente en modo estricto de desarrollo React.StrictMode), lo que hace que el componente se monte, se desmonte y se vuelva a montar muy rápido. La librería html5-qrcode inserta un elemento <video> en el DOM. Al montarse dos veces rápido, la librería crea dos instancias de video antes de que la primera se limpie correctamente.

El Problema de Lectura (No escanea):

La doble cámara: Al tener dos instancias de video peleando por el recurso de la cámara, el procesador de QR se confunde o se bloquea, impidiendo la lectura.

La Cámara de Notebook: Como bien intuiste, las cámaras de notebook suelen tener foco fijo y baja resolución. Los códigos QR generados con nivel de corrección "H" (High, como está en tu código) son muy densos (muchos puntitos). Si la cámara no tiene autofocus, se ve borroso y no lee. Solución: Prueba con el celular o aleja/acerca el QR lentamente.

2. Solución al Código (Scanner y Mapa)
Vamos a arreglar tres archivos:

ScanScreen.tsx: Para arreglar la doble cámara y mejorar la limpieza de memoria.

MapScreen.tsx: Para mover el botón (que no tape el menú) y agregar el botón de "Ingreso Manual".

App.tsx: Para conectar la lógica de ingreso manual al mapa.

// Archivo: QR-escaneo/screens/ScanScreen.tsx

import React, { useState, useEffect, useRef } from 'react';
import { Html5Qrcode, Html5QrcodeSupportedFormats } from 'html5-qrcode';
import { getItemByQrId } from '../services/itemService';
import { Item, ItemStatus } from '../types';
import Spinner from '../components/Spinner';

interface ScanScreenProps {
  onScanComplete: (result: { item: Item; status: ItemStatus }) => void;
  onCancel: () => void;
}

const SCANNER_ELEMENT_ID = 'qr-reader';

const ScanScreen: React.FC<ScanScreenProps> = ({ onScanComplete, onCancel }) => {
  const [isLoading, setIsLoading] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const scannerRef = useRef<Html5Qrcode | null>(null);

  useEffect(() => {
    // 1. Limpieza preventiva por si React StrictMode renderiza doble
    const element = document.getElementById(SCANNER_ELEMENT_ID);
    if (element) element.innerHTML = "";

    const scanner = new Html5Qrcode(SCANNER_ELEMENT_ID);
    scannerRef.current = scanner;

    const config = { 
      fps: 10, 
      qrbox: { width: 250, height: 250 },
      aspectRatio: 1.0,
      formatsToSupport: [ Html5QrcodeSupportedFormats.QR_CODE ]
    };

    // Iniciamos el escáner
    scanner.start(
      { facingMode: "environment" }, 
      config,
      async (decodedText) => {
        // --- LÓGICA DE ÉXITO ---
        await scanner.stop(); // Detener cámara inmediatamente
        scanner.clear();      // Limpiar UI
        
        setIsLoading(true);
        setError(null);

        try {
          // Aquí se ejecuta la lógica que pediste: buscar el item
          const result = await getItemByQrId(decodedText.trim());
          if (result) {
            onScanComplete(result); // Esto llevará a App.tsx que decide si es Transferencia o Reporte
          } else {
            setError('QR no encontrado en la base de datos.');
            setIsLoading(false);
          }
        } catch (err) {
          setError('No se pudo verificar el QR.');
          setIsLoading(false);
        }
      },
      (errorMessage) => {
        // Error de lectura frame a frame, lo ignoramos para no saturar
      }
    ).catch(err => {
      console.error("Error al iniciar cámara:", err);
      setError("No se pudo acceder a la cámara. Verifique permisos.");
    });

    // Cleanup function: Se ejecuta al cerrar el componente
    return () => {
      if (scannerRef.current && scannerRef.current.isScanning) {
        scannerRef.current.stop().then(() => scannerRef.current?.clear()).catch(console.error);
      }
    };
  }, [onScanComplete]);

  return (
    <div className="absolute inset-0 bg-black/90 flex flex-col items-center justify-center z-50 p-4">
      <div className="w-full max-w-md bg-[#1e2a47] rounded-lg p-4 text-white text-center relative">
        <h2 className="text-xl font-bold mb-4 text-yellow-400">ESCANEAR QR</h2>

        {isLoading ? (
          <div className="flex flex-col items-center justify-center h-[300px]">
            <Spinner />
            <p className="mt-4 text-yellow-400 animate-pulse">Verificando item...</p>
          </div>
        ) : error ? (
          <div className="flex flex-col items-center justify-center h-[300px]">
            <p className="text-red-500 mb-4 px-4">{error}</p>
            <button onClick={onCancel} className="bg-gray-600 text-white py-2 px-6 rounded-lg">
              Cerrar
            </button>
          </div>
        ) : (
          <>
            {/* Contenedor del video */}
            <div id={SCANNER_ELEMENT_ID} className="w-full overflow-hidden rounded-lg bg-black"></div>
            <p className="mt-4 text-gray-400 text-xs">Apunta la cámara al código QR del item</p>
            
            <button
              onClick={onCancel}
              className="mt-4 w-full bg-red-600 hover:bg-red-700 text-white py-3 rounded-lg font-bold"
            >
              CANCELAR
            </button>
          </>
        )}
      </div>
    </div>
  );
};

export default ScanScreen;

Resumen de la Lógica
Escaneo:

Cuando el escáner lee (o ingresas el código manual), llama a onScanComplete.

En App.tsx, handleScanComplete hace esto:

Si el item es tuyo -> Muestra detalle (ResultScreen).

Si el item NO es tuyo -> Abre Screen.REQUEST_TRANSFER. Esto cumple tu requerimiento de "funcionalidad de vender".

Si el item está denunciado -> ResultScreen muestra un cartel rojo gigante de "ROBADO".

Cámara Notebook:

Es muy probable que la cámara de la PC no pueda enfocar el QR de cerca. Prueba generando el QR en el celular y mostrándolo a la PC un poco más lejos, o viceversa.

Si funciona en el celular pero no en la PC, el código está bien, es solo limitación de hardware de la cámara web.
